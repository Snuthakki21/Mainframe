# Framework development evidence

Numbered logs retain failing tests, investigations and successful reruns. A failing
or interrupted intermediate log is not the release result. 17-all-tests.txt is the
last development suite: 91 passed. 14-matrix-full.txt records the initial complete
nine-target matrix. The final exact-archive test is separate and runs after packing;
its machine receipt and human report are delivered alongside the ZIP. Running
VERIFY-WINDOWS.cmd creates your own environment-specific evidence/package-check log.

The review was conducted in this assistant session, not an independent external
firm. None of these logs represents live mainframe, Oracle, BigQuery, .NET, Windows
or vendor-hosted Copilot/Devin execution.
